# Аналитический отчет по погоде

Мы можем сделать несколько выводов на основе предоставленной информации:

1.  **Среднегодовая температура:** Для Лондона в целом средняя температура за год составляет примерно +11,8°C. В этом случае среднемесячная температура составила всего 6,8°C, что ниже нормы.
2.  **Температура максимума.** В Лондоне обычно наблюдается максимум +22,5°С. Однако в этом случае он был заметно ниже этой нормы — 12,9 °С.

В целом можно сказать, что за этот период погода была несколько холодной для стандартов Лондона.
