# Data Dictionary – mart витрина (variant_04, London)

- **Версия:** 1.0.0
- **Дата:** 2026-06-09
- **Слой данных:** Mart (суточная аналитическая витрина)
- **Файловый источник:** `data/mart/variant_04/mart_YYYY-MM-DD.csv`
- **Таблица в СУБД PostgreSQL:** `weather_london_daily_mart`

---

## Описание набора данных

Аналитическая витрина данных представляет собой плоскую денормализованную структуру, содержащую агрегированные суточные метеорологические показатели по городу Лондон (Великобритания). Данные извлекаются в инкрементальном режиме из Open‑Meteo Archive API, проходят полный цикл очистки, валидации через Data Quality Gate и сохраняются в реляционную базу данных.

**Зернистость данных (Grain):** Одна строка базы данных строго соответствует уникальной комбинации календарных суток и идентификатора локации (`date` + `city_id`).

**Бизнес-контекст:** Мониторинг климатических изменений, проведение среднесрочного анализа трендов погоды, выявление аномальных выбросов и обеспечение очищенными данными корпоративных BI-систем отчетности (Metabase).

## Техническая спецификация колонок таблицы `weather_london_daily_mart`

### 1. date
| Свойство | Значение |
| :--- | :--- |
| **Технический тип в БД** | `DATE` |
| **Nullable** | NO (Входит в состав Composite Primary Key) |
| **Единица измерения** | Календарные сутки (YYYY-MM-DD) |
| **Бизнес-описание** | Дата, за которую рассчитаны суточные агрегированные показатели |
| **Алгоритм формирования** | Выделяется из почасовой метки `ts` слоя `Normalized` |
| **Пример значения** | `2024-01-01` |
| **Ограничение (Constraint)** | Значение `date` ≤ `CURRENT_DATE` (Запрещены будущие даты) |

### 2. city_id
| Свойство | Значение |
| :--- | :--- |
| **Технический тип в БД** | `VARCHAR(10)` |

| **Единица измерения** | Строковый код-идентификатор |

## Промышленные примеры SQL-запросов к СУБД PostgreSQL

Вы можете выполнять данные аналитические запросы для проверки работоспособности базы данных:

### 1. Поиск критических температурных экстремумов
```sql
SELECT 
    date, 
    min_temp, 
    max_temp, 
    (max_temp - min_temp) AS temp_amplitude
FROM weather_london_daily_mart
WHERE city_id = 'GB_LON'
ORDER BY temp_amplitude DESC
LIMIT 5;
```
